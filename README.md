# 🎮 Python Mini Games Collection

This repository contains **6 beginner-friendly Python mini games** created to practice basic programming concepts such as loops, conditions, functions, random module, and user input.

## 📌 Games Included

1. 🪨 Rock Paper Scissors
2. 🔢 Number Guessing Game
3. 🎲 Dice Rolling Simulator
4. ⚖️ Even or Odd Game
5. 🔐 Password Verification
6. 🎯 Hangman (Guess the Word)

## 🚀 Features

- Beginner-friendly Python code
- Console-based games
- Uses Python built-in functions and the `random` module
- Great for learning programming logic

## 🛠️ Technologies Used

- Python 3

## 📚 Purpose

These mini projects were built to improve my Python programming skills and gain hands-on experience with basic game development.
